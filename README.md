# CoWork Manager - Projet de Fin d'Année B2

Bienvenue sur le dépôt du projet de fin d'année B2 du groupe de **Sonny Ferreira**.

Ce projet est une solution complète de gestion intelligente d'un espace de coworking pour la société **Laceris Tech** (réservation, accès, facturation et administration).

## Documentation du Projet

Une documentation technique et fonctionnelle complète et exhaustive est disponible dans le fichier suivant :
*   [DOCUMENTATION.md](file:///c:/0personnel/cours/informatique/projet-fin-dannee-b2/DOCUMENTATION.md)

Vous y trouverez :
1. L'architecture technique globale.
2. Le modèle de données SQLite détaillé.
3. Le fonctionnement des différents services de l'application (Active Directory, QuestPDF, Emails/Graph API, Rappels automatisés).
4. Le guide d'installation, configuration et démarrage rapide.
5. La matrice des droits et rôles de l'application.

## Technologies Clés
*   **Back-end** : ASP.NET Core Razor Pages & Minimal APIs (.NET 10.0)
*   **Base de données** : SQLite
*   **Services** : LDAP/Active Directory, QuestPDF (facturation), QRCoder (contrôle d'accès), MailKit & Graph API (notifications).
